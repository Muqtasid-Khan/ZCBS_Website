# ZCBS brand identity

**Concept.** An *arch* (institution, the architecture of a university) encloses a *flame* (knowledge and leadership) carried on a *pillar*
(character, integrity) that rises from an *open book* (learning). Geometric, symmetrical, two weights of line — legible at 16 px.

| Role | Value |
|---|---|
| Navy (primary) | `#0B1B2E` |
| Gold (accent) | `#C9A24B` — darker gold for text on light: `#8A6D22` |
| Ivory (background) | `#F6F1E7`, paper `#FBF8F1` |
| Headings | Cormorant Garamond 600/700 (self-hosted) |
| Body | Inter (self-hosted) |
| Buttons | Rectangular, 3 px radius, uppercase, letter-spaced; gold (primary) / navy / outline |
| Cards | White, 1 px warm border, 6 px radius, soft shadow, gentle lift on hover |
| Icons | Bootstrap Icons |
| Backgrounds | Navy with fine gold arch line pattern; ivory alternating sections |

Logo files are in `static/brand/` (generated by `tools/make_brand.py`):
`zcbs-logo-primary.svg/.png` (transparent, for light backgrounds), `zcbs-logo-primary-light.*` (for dark backgrounds),
`zcbs-logo-primary-on-ivory.png`, `zcbs-logo-mono-black.*`, `zcbs-logo-mono-white.svg`, `zcbs-logo-horizontal*.svg/.png`,
`zcbs-logo-compact*.svg`, `zcbs-emblem*.svg/.png`, `favicon.svg/.ico/-32/-512.png`, `apple-touch-icon.png`, `og-card.png/.svg`.
Text in all SVGs is converted to outlines, so they render the same everywhere. The emblem is original and does not imitate the BZU emblem.
Change the website logo any time in *Website settings → Logo*.
